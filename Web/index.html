Teenio Web help

    
First connection

    
    
      
  1. Use Chrome 117 or later on macOS or Windows.
    2. 
      
  2. Pair TEENIX97 in the computer’s Bluetooth settings.
    3. 
      
  3. On the calculator, hold f, press + to reach ConnEct AY En, then press A.
    4. 
      
  4. Choose Connect to TEENIX97 and select the board in Chrome’s chooser.
    5. 
      
  5. Choose Read settings. A valid board reports HP-97 firmware 21.
    6. 
    

    
Clock, memory and stored programs

    
Read clock performs the firmware-21 clock exchange. A clock write is available only after a successful live read and asks for confirmation before changing the board. Read memory & registers transfers all 448 active RAM bytes and then displays the sixteen primary registers, all 224 program positions or the raw 64-register capture.

    
Stored programs scans a block's 54-slot directory and reads one 150-byte card without changing it. Captures use the same checked .calcom-slot format as Teenio for Mac. Valid HP-97 .hpp files can be opened and exported. A vacant slot cannot be exported as a program.

    
Reopen memory and export a complete program

    
    
      
  1. In Memory & registers, read the calculator or choose Open memory capture… and open a Teenio memory text report. Mac and Web reports are supported. The date, source and all 64 RAM rows are checked. A text report has no checksum; keep an unedited original. A program listing is not a memory capture.
    2. 
      
  2. Use Choose card template… to go to Stored programs. Read an existing program card, or open an HPP file or saved card capture. This supplies the display/trigonometry settings and flags; it does not supply the program instructions. A vacant slot cannot be a template.
    3. 
      
  3. Return to Memory & registers, enter a short program name and choose Prepare two cards. All 224 positions are preserved as two cards, even if the program is short. The source memory and template remain unchanged.
    4. 
      
  4. Save both numbered HPP files. Load card 1 followed by card 2 using CalCom or the calculator’s stored-card controls. These files contain program instructions, not the sixteen numeric registers. Keep the full memory report separately.
    5. 
    

    
Changing the memory capture, template card or name clears prepared exports so the next export uses the new source. Demo-derived cards and filenames are labelled DEMO. HPP files contain no source or Demo metadata. Exporting sends no calculator commands; it does not upload or load a program.

    
Write one stored card

    
    
      
  1. Read settings to verify HP-97 firmware 21, then open an HP-97 card or read a source slot.
    2. 
      
  2. Choose the destination block and slot. Clicking a directory entry selects it without replacing the current source card.
    3. 
      
  3. Choose Write to selected slot… and check the source name and destination in the review.
    4. 
      
  4. Choose a new backup file when prompted. Teenio freshly reads the destination, saves its exact bytes and reopens the file to check it before writing. Cancelling or a backup failure stops the write.
    5. 
      
  5. Wait for written and verified, then scan the directory again. The check compares all 150 bytes. Load the stored card through the calculator’s card-read controls to run it.
    6. 
    

    
Live writing needs desktop Chrome’s file-saving support. Keep the page open and the calculator powered during a write. If it fails after writing starts, the destination may have changed: retain the backup and reconnect to inspect the slot. Teenio does not retry or restore automatically. Single-slot writing does not load active program memory.

    
Demo writing changes only the browser’s temporary Demo storage and verifies a separate read from it. Demo backups are held in memory until saved; Demo captures cannot be written directly to the real calculator.

    
Upload two cards, then verify the loaded program

    
    
      
  1. Prepare both cards from a memory capture as described above. Choose Choose upload destination… to return to Stored programs.
    2. 
      
  2. Scan the intended block and select the first of two adjacent slots. Prefer two vacant slots. The first slot must be 00–52; the pair cannot cross a block boundary.
    3. 
      
  3. Choose Upload both cards…, check the names and both destinations, then choose a new backup file. Teenio reads current RAM and both destination slots, saves them together and reopens the file to check every byte before either slot is written.
    4. 
      
  4. Wait for both stored cards to be verified. Card 1 is written and separately read back before card 2 starts. A failed write or read-back stops the pair with no automatic retry or restore.
    5. 
      
  5. On the HP-97 in RUN mode, hold f, choose CARD → Read, select the first destination and press ENTER. At Crd, press ENTER to load the following card.
    6. 
      
  6. Before running the program or changing registers, choose Verify loaded program. It makes a fresh RAM read, compares all 224 program positions with the prepared source, and checks that the sixteen primary registers are unchanged from before upload. Save the verification report if wanted.
    7. 
    

    
If the source program was already active before uploading, matching memory cannot prove that loading happened. Teenio reports this explicitly. Keep this page open until verification is finished; you may disconnect and reconnect the same calculator and read settings again. Reloading the page or switching Demo mode clears the pending comparison.

    
In Demo mode, uploading changes only stored cards. Use Simulate loading both cards before verifying; verification alone never loads them. Save the Demo upload backup to keep it after closing the page.

    
Keep and reopen upload backups

    
Under Two-card backup files, open a saved upload backup (.json) and extract its full memory report or either original .calcom-slot capture. The file includes checksums for all three captures, including vacant or unrecognised slots. Opening it neither restores calculator data nor resumes a pending verification. Valid original program cards can be restored through the single-slot write workflow; restoration of vacant or unrecognised slots and numeric-register writing are not implemented.

    
Privacy and safety

    
This milestone runs locally in your browser. It sends calculator bytes only through the serial device you select and does not upload them to a server. Demo mode never opens Bluetooth.
